# 按现象排错

这一篇按你看到的现象索引，每条都是「现象 → 先看什么 → 怎么处理」。协议细节见 [PAIRING.md](PAIRING.md)，页面说明见 [SCREENS.md](SCREENS.md)。

## 安装

| 现象 | 先看什么 | 怎么处理 |
|---|---|---|
| 提示「解析包出错」 | 文件是否下完整 | 重新下载，对照 `SHA256SUMS.txt` 校验 |
| 提示「应用未安装」 | 手机上是否已有同包名但签名不同的旧包 | 先卸载旧包再装；签名不同不能覆盖 |
| 系统不让安装 | 是否开了未知来源 | 给打开文件的那个应用「安装未知应用」权限 |
| 装上了但打不开 | 是否 Android 8.0 以下 | 最低 API 26，低于它就装不上 |

## 连接

| 现象 | 先看什么 | 怎么处理 |
|---|---|---|
| 一直停在未配对 | 桌面远程通道是否打开 | 回桌面「设置 → 手机配对」打开通道，再重新生成配对码 |
| 提示不是本机的配对码 | 票据里的公钥是否属于这台手机 | 在手机上重新复制配对请求，让桌面重签 |
| 提示配对码已过期 | 是否超过 90 秒 | 回桌面重新生成；旧码不会复活 |
| 提示缺中继地址 | 桌面局域网通道是否起来 | 检查端口占用与网卡，再重新生成票据 |
| 证书指纹不匹配 | 是否换过电脑或重装过桌面 | 撤销旧设备后重新配对 |
| 已配对但一直离线 | 是否同一局域网、是否开了 VPN | 关 VPN，确认同一路由器且未开 AP 隔离 |
| 断线后不停重试 | 关闭码是否 4401/4402/4403 | 直接停止重连，回桌面撤销后重新配对 |
| 桌面能看到手机，手机看不到桌面 | 防火墙是否拦了端口 | 放行对应端口，或临时关防火墙验证 |

## 页面

| 现象 | 先看什么 | 怎么处理 |
|---|---|---|
| 工位页没有「进对话」 | 是否在线 | 未连接时这个入口不显示，先解决连接 |
| 待我决定显示「读不到」 | 是否在线 | 未连上时这一格不显示数字，也不显示 0 |
| 审批页一开始就全部「已失效」 | 审批是否有 120 秒有效期 | 超过 120 秒的审批只能拒绝，回桌面重新发起 |
| 允许按钮是灰的 | 是否录入了生物识别 | 设置 → 关于里看生物识别状态；未录入时只能拒绝 |
| 允许按钮是灰的（另一情况） | 工具是否危险 | 危险工具在手机上不提供允许 |
| 协作页按钮都不见了 | 桌面是否缺项目/会话/任务 id | 缺 id 时保持只读，属于正常降级 |
| 作品页说「读不到作品库」 | 在线状态与 `works.get` 是否回了结果 | 确认在线后重进页面再拉一次 |
| 作品页说「电脑上还没有作品」 | 桌面是否真的没有作品 | 这是拿到空列表后的说法，不是断网 |

## 通知

| 现象 | 先看什么 | 怎么处理 |
|---|---|---|
| 收不到任何通知 | 系统通知权限 | 设置 → 通知里有状态与跳转入口 |
| 只有审批有提醒 | 免打扰是否开着 | 免打扰期间完成与卡住会合并成一条汇总 |
| 某个渠道没声音 | 该渠道重要性 | 渠道重要性由系统设置决定，应用不会偷偷改回去 |
| 点通知没跳转 | 应用是否被杀 | 进程被回收后不会推送；回到前台会补拉 |
| 任务跑到一半没通知了 | 前台服务是否被系统停 | 极端省电策略下仍可能被杀，锁屏期间不保证及时 |

## 构建

| 现象 | 先看什么 | 怎么处理 |
|---|---|---|
| `aapt2` 报资源错误 | 工程路径是否含非 ASCII 字符 | 把工程放到纯 ASCII 路径下再构建 |
| 找不到 system-image | SDK 路径是否含非 ASCII 字符 | 同上；SDK 也放到纯 ASCII 路径 |
| `assembleRelease` 直接失败 | `keystore/keystore.properties` 是否存在 | 没有签名配置时 release 变体不产出，这是刻意的行为 |
| 测试一大片红 | 是否合并过测试类 | 测试类逐字保留，合并会破坏 Robolectric 沙箱隔离 |
| 静态断言莫名全绿 | 文件是否被移动 | 断言引用的路径失效会被跳过，检查 `verify.sh` 的路径列表 |

## 收集信息

报问题前先收齐这些：

- 应用版本（设置页「关于」里的版本号）与 Android 版本。
- 连接状态截图：工位页的四个标签与在线时长。
- 桌面端版本，以及「设置 → 手机配对」面板上的状态。
- 是否同一局域网、是否开过 VPN、路由器是否开了 AP 隔离。
- 如果是构建问题，附上 `bash scripts/verify.sh` 的完整输出。

桌面端的现象（模型连不上、任务跑不动、打包失败）在另一个仓库：<https://github.com/youyuwangzi0001/Morrow>。
